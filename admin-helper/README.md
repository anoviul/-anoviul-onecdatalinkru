# Помощник администратора — Жёлтый мост

Локальная программа под Windows. Искусственный интеллект через сервис Жёлтый мост
предлагает команду PowerShell, а человек за этим компьютером решает, выполнять ее
или нет. По умолчанию каждая команда выполняется только после подтверждения на
экране; есть добровольный режим доверия (см. ниже), в котором следующие команды
идут без отдельного окна. Команды выполняются под правами текущего пользователя,
без повышения прав.

Входящих соединений в компьютер нет: помощник сам обращается к сервису короткими
запросами по HTTPS и забирает задания.

## Два варианта клиента

Протокол и гарантии у них одинаковые, выбирайте по тому, что есть на машине.

- `helper.ps1` + `helper_flow.ps1` + `progress_send.ps1` — клиент на PowerShell, без
  установки Python. Работает на Windows 11 и на Windows Server 2008 R2 (PowerShell 2.0
  на .NET 4 через лончер `run_ps.cmd`). Это основной вариант.
- `helper.py` — тот же клиент на Python 3.10+, если Python уже установлен.

## Что нужно для подключения

1. Получите ключ помощника. Ключ выдается в личном кабинете на onecdatalink.ru,
   тип «Помощник администратора». Ключ приходит выключенным.
2. Скопируйте `config\config.example.json` в `config\config.json` и впишите ключ
   в поле `token` (адрес `base_url` уже заполнен). Больше ничего заполнять не нужно.
3. Запустите помощник под ОБЫЧНЫМ пользователем (не «от администратора»):
   - PowerShell: двойной клик по `run_ps.cmd`;
   - Python: двойной клик по `run.cmd`.
   Помощник зарегистрирует сеанс и покажет «ожидает подтверждения».
4. Подтвердите этот компьютер в кабинете — ключ включится, окно напишет, что
   помощник работает.
5. Когда ассистент пришлет команду, на экране появится окно с ее полным текстом:
   «Разрешить», «Отклонить» или «Разрешить все до остановки».

## Файлы в корне

- `run_ps.cmd` — запуск клиента на PowerShell (сам поднимает .NET 4 ради TLS 1.2,
  установки чего-либо не требует).
- `run.cmd` — запуск клиента на Python.
- `stop.cmd` — остановить свой запущенный помощник и снять замок. Останавливается
  только процесс, запущенный из этой папки; рабочее состояние не затрагивается.
- `progress_send.ps1` — служебный: пересылает ход долгой команды (запускается
  помощником сам, вручную его трогать не нужно).

## Папки

- `config\` — настройки. `config.json` вы создаете сами из `config.example.json`;
  в репозиторий он не попадает.
- `logs\` — журнал работы `helper.log` (с ротацией).
- `runtime\` — рабочее состояние (создается само): журнал операций, замок второго
  запуска, временные файлы хода. Содержимое удалять не нужно.

## Модель сеанса

Каждый запуск — новый сеанс со случайным идентификатором, который живет только в
памяти процесса. Пока окно открыто, сеанс активен. Закрыли окно — запись о сеансе
снимается и ключ гаснет. Если окно закрыли жестко, сеанс снимется по таймеру на
стороне сервиса.

## Задание и ход выполнения

Ассистент при постановке команды задает короткое название задания — оно печатается
в окне помощника, чтобы вы видели, к чему относится команда. Долгую команду ассистент
пишет так, чтобы она сама отмечала ход (переменная окружения `ODL_PROGRESS`), а
помощник пересылает этот ход на сервис — ассистент видит, что происходит, не дергая
вас. Файлы хода живут в `runtime\` только на время команды.

## Безопасность

- По умолчанию каждая команда выполняется только после того, как вы нажали
  «Разрешить» в окне на этом экране. Если команду не подтвердить, по таймауту она
  отклоняется.
- Кнопка «Разрешить все до остановки» включает режим доверия: пока помощник не
  остановлен, следующие команды выполняются БЕЗ отдельного окна (каждая печатается
  в консоль и в журнал). Это осознанное ослабление, включаете его только вы; режим
  сбрасывается при остановке и повторном запуске помощника.
- Повышение прав не поддерживается, запуск «от администратора» отклоняется.
- Адрес сервиса принимается только по HTTPS.
- Настройки, журнал и рабочее состояние защищаются правами доступа только для вашей
  учетной записи; если защиту поставить не удалось, помощник не работает.
- Вывод команды возвращается ассистенту — не передавайте в командах лишние секреты.
